# PEEM-style eval gate (from Agentic Practitioner Playbook)

Run after generation, before ship. Score each axis 1–5. Fix anything ≤3.
Do not expand context to "try harder" — fix architecture (Select / Compress / Isolate).

## Structural (pre-run)

| Axis | Pass looks like |
|------|-----------------|
| Clarity | Single verb for this turn; no conflicting goals |
| Structure | SYSTEM → brief → one playbook → phase only |
| Fairness | Brand facts sourced; no invented licenses/reviews |
| Conciseness | Under budget in `CONTEXT-PACKING.md` |
| Relevance | Only this surface's tier + identity lock loaded |

## Output (post-run)

| Axis | Pass looks like |
|------|-----------------|
| Accuracy | NAP, prices, licenses match brief |
| Coherence | One type pairing, one accent, one interaction grammar |
| Objectivity | Claims are falsifiable; no buzzword soup |
| Clarity | Headlines fit only this brand |
| Restraint | No techniques above declared tier |

## Hill-climb loop

1. Diagnose by theme (slop fingerprint vs missing craft vs context rot)
2. Apply **one** architectural fix (usually Isolate a phase or Select a tighter playbook)
3. Re-run the phase only
4. Re-score; stop when all required axes ≥4 and `AUDIT.md` is clean

## Regression vs failure-mode

- **R:** Re-check hard bans from `SYSTEM.md` after every polish pass
- **F:** Explicitly probe for cream/terracotta cluster, Inter fallback, three-card grids, Zap/Shield/Rocket rows
