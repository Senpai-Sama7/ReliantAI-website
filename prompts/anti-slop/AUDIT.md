# God-tier gate (anti-slop + tier excellence)

Run both. Pass only with zero slop violations AND strong scores on required criteria.

## Anti-slop audit

```
Audit codebase + rendered output against the 2026 AI-slop checklist:
- Zero blue/indigo/purple-pink signature gradients
- Zero cream + terracotta + serif "AI cluster" looks
- Only the two chosen fonts; no silent Inter/system display
- No three-equal-card feature grids; no Zap/Shield/Rocket stamp rows
- No cards in the hero; hero budget respected
- No transition-all duration-300 ease-in-out spam
- No copy using: seamless, cutting-edge, unlock, elevate, robust, best-in-class,
  leverage, delve, holistic, transformative, empower, "in today's [x] world",
  "It's not just X — it's Y"
- Em dashes minimized; real alt; real meta + OG
- One interaction grammar sitewide
- Data surfaces have empty/loading/error/partial/success where interactive
Report every violation and fix it.
```

## Excellence audit

```
This build targets tier [T0|T1|T2|T3].
Score 0–2 on every criterion the tier requires:
identity, states/forms, a11y, performance, copy,
[reveals, cinematic scroll, kinetic type, interaction grammar, atmosphere as applicable].
Flag any technique ABOVE the declared tier as a restraint violation.
For every score < 2, propose a concrete fix that does not reintroduce slop.
```

## T1 local-business strong signals

- Could not be mistaken for another contractor after removing the nav
- Named Houston neighborhoods / license numbers / hours / phone in real UI
- Emergency CTA works on mobile (tap-to-call)
- CSS scroll-driven or restrained JS reveals tied to meaning
- Asymmetric service presentation (not three identical cards)
